# 🐍 Snake Game (Python)

A classic Snake Game developed using Python.
The player controls the snake to eat food, grow longer, and avoid collisions.

---

## 🚀 Features

* 🎮 Keyboard-controlled snake movement
* 🍎 Food generation system
* 📈 Score tracking
* 💀 Game over on collision (wall/self)
* 🔄 Restart functionality

---

## 🛠️ Tech Stack

* **Language:** Python
* **Library:** Pygame (or mention if you used Turtle)

---

## 🎮 Controls

* ⬆️ Up Arrow → Move Up
* ⬇️ Down Arrow → Move Down
* ⬅️ Left Arrow → Move Left
* ➡️ Right Arrow → Move Right
